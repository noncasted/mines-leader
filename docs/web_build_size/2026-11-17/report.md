«До»: Addressables, `origin/main` `e895fe1d` (framework `a11e507a`), сборка `builds/web-2026-11-17-addressables`, контент LZ4.
«После»: ветка `framework-0.9.0` `42040995` (framework `10762143`, v0.9.0: AssetBundles движка вместо Addressables), деплойная сборка
`builds/web-2026-11-17-deploy` (`deploy-client.sh web --no-deploy`). Обе: Unity 7000.0.0a10, профиль `web_dev - Desktop - Development`.

## Что изменилось и почему

1. **Код без Addressables.** Из `ScriptingAssemblies.json` ушли `Unity.Addressables` и `Unity.ResourceManager` (пришли
   `Framework.Common`, `Framework.Session.Core`, `Internal.Animations`, `Internal.Layout`, `Internal.UGUI`): `wasm` -0,66 МБ распакованным,
   -0,26 gzip, метаданные -0,09 gzip. Движок без контента -0,34 gzip.
2. **`.data` вырос на 0,025 только из-за контента:** `Main` + `SharedCommon` (0,111) предзагружены в нём, без них `.data` меньше на 0,085.
   Каталог (json 10 КБ) добавил к `data.unity3d` +0,006 вместо `catalog.bin` + `settings.json` (0,008).
3. **Контент меню вдвое легче** (0,424 -> 0,214) и почти без запросов (22 -> 4): нет отдельных `unitybuiltinassets` / `monoscripts`
   (0,115), сцены меню и игровые представления меньше. Разложить разницу по ассетам нельзя: у нового билда нет `buildlayout`.
4. **Музыка отдельно** (`Music`, 0,489, без gzip - аудио не жмётся), меню её не ждёт: до меню без музыки 4,194 МБ в проде против 4,778.
5. **Сжатие при передаче.** Новый контент лежит в `.gz` (поверх LZ4HC -4..-28%), старый прод отдавал LZ4 без сжатия, отсюда -0,73 МБ
   до матча в проде против -0,64 в одинаковом gzip.
