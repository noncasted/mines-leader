# Реализованные: Усиление

Карты категории усиления улучшают характеристики игрока — ходы, HP, ману и эффекты карт.

Все реализованные карты: [[cards_implemented_all]]

### Trebuchet Aimer

> Мана: 2 | Цель: себя | Без позиции

Добавляет +1 к модификатору TrebuchetBoost. Каждый буст увеличивает эффект [[cards_implemented_cross#Trebuchet|Trebuchet]] на 2 клетки. Сбрасывается после использования Trebuchet. Стакается.

### Overclock

> Мана: 3 | Цель: себя | Без позиции

+2 дополнительных действия в текущем ходу. Не переносится на следующий ход.

### Medic

> Мана: 4 | Цель: себя | Без позиции

Восстанавливает 1 HP. Не может превысить максимум.

### Purge

> Мана: 2 | Цель: себя | Без позиции

Снимает все активные эффекты (Smoke, Fog) с каждой клетки своего поля.
