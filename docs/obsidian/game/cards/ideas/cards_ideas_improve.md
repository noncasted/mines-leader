# Идеи: Усиление

## Adaptive Armor

**Мана:** 2
**Цель:** Себя
**Длительность:** Перманентно

Каждый раз, когда игрок получает урон от подрыва мины, размер паттернов всех его карт увеличивается на 1. Эффект накапливается и не сбрасывается.

Comeback-механика: чем хуже идут дела, тем мощнее становятся карты. Создаёт обратную зависимость между успехом и силой.

**Вопросы для проработки:**
- Применяется к паттернам всех карт или только определённых категорий?
- Есть ли верхний предел накопления?
- Как отображать текущий бонус к паттернам на клиенте?
- Взаимодействие с картами, у которых нет фиксированного паттерна (например, Overcharge)?

## Wild Surge

**Мана:** 2
**Цель:** Себя
**Тип:** рулетка (4 баффа)

Случайный бафф из 4: +2 хода / +3 маны / Draw 2 / +1 ко всем паттернам. Все варианты полезны, нет пустого исхода. Неплохая идея для рандомного баффа.

## Lucky Charm

**Мана:** 1
**Цель:** Себя
**Тип:** пассивный бафф

+10% к удачным исходам всех рандомных карт в этом ходу. Стакается. Мета-карта для лудоманских колод — без рандомных карт бесполезна. Имеет смысл добавлять только если будет достаточно рандомных карт в пуле.
