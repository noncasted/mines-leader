# Идеи: Колода

## Evolution

**Мана:** 4
**Цель:** Себя
**Таргетинг:** Выбор карты из руки

Перманентно улучшает одну карту в руке до её _Max версии. Игрок сам выбирает какую карту улучшить.

Новый тип таргетинга: выбор карты из руки. Требует отдельной реализации UI — нажатие на карту в руке вместо клетки на доске.

**Вопросы для проработки:**
- Как реализовать выбор карты из руки на клиенте?
- Что происходит если в руке нет карт с _Max версией?
- Сохраняется ли улучшение при возврате карты в колоду (через Gravedigger и подобные)?

## Random Tax

**Мана:** 2
**Цель:** Противник
**Тип:** кость d3

Кость d3: противник сбрасывает 1, 2 или 3 случайные карты из руки в стэш. Рандомная версия Confiscate, дешевле но непредсказуемо.

## Chaos Scramble

**Мана:** 2
**Цель:** Противник
**Тип:** кость d5

Кость d5: противник сбрасывает N карт и тянет N новых из колоды. Рандомная версия Hand Scramble. Похоже на существующую карту, нужно сравнить.
