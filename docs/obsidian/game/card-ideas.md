# Идеи новых карточек

Анализ текущей системы и предложения новых карт, заполняющих неиспользованное пространство дизайна.

## Статус реализации

**Реализовано:** 8 из 11 идей (Medic, Minefield Scout, Siphon, Chain Reaction, Overclock, Fog of War, Scavenger, Hand Scramble)

**Отклонено:** 3 карты (Mirror Wall, Landslide, Decoy) — см. [cards-fail.md](cards-fail.md)

## Анализ текущих карт

### Распределение по ролям

| Роль | Карты | Кол-во |
|------|-------|--------|
| **Атака (мины)** | Trebuchet | 1 |
| **Атака (урон)** | Opponent Bomb, Chain Reaction | 2 |
| **Атака (саботаж)** | Flag Erase, Flag Reshuffle, Smoke, Fog of War | 4 |
| **Защита (открытие)** | Bloodhound, Erosion Dozer, Zip Zap, Minefield Scout | 4 |
| **Утилити (буфф)** | Trebuchet Aimer, Overclock | 2 |
| **Утилити (ресурс)** | Gravedigger, Scavenger | 2 |
| **Утилити (контроль)** | Siphon, Hand Scramble | 2 |
| **Утилити (лечение)** | Medic | 1 |

### Оставшееся неиспользованное пространство дизайна

| Возможность | API | Текущий статус |
|------------|-----|--------|
| Манипуляция маной (дренаж) | `Mana.Use()` / `Mana.Restore()` | Siphon использует базовый функционал |
| Манипуляция ходами (блокировка) | `Moves.Restore()` / `Moves.Lock()` | Не используется |
| Новые эффекты клеток | `CellEffectType` | Smoke, Fog of War используются |
| Новые модификаторы | `PlayerModifier` | Только TrebuchetBoost; планируются для новых карт |

**Реализовано:**
- ✅ Лечение — `Medic` использует `Health.Heal()`
- ✅ Цель: противник — `Siphon` и `Hand Scramble` используют `CardTarget.Opponent`
- ✅ Добор из колоды — `Scavenger` берёт карты из колоды, `Gravedigger` из сброса
- ✅ Линейные паттерны — `Minefield Scout` использует линию

### Баланс-наблюдения (после реализации 8 идей)

- **Урон теперь есть** — Opponent Bomb (условный), Chain Reaction (каскадный). Целевой урон существует
- **Хил реализован** — Medic восстанавливает HP, играет роль страховки
- **Контроль игры развился** — Siphon и Hand Scramble мешают стратегии противника
- **Комбо разнообразнее** — Overclock + Scavenger, Fog of War + Flag Reshuffle, Minefield Scout для разведки
- **Остаётся без реактивных эффектов** — все карты проактивные, нет ловушек или отложенных триггеров

## Возможные направления развития

Текущая колода достаточно сбалансирована с реализованными 18 картами. Возможные направления для новых карт:

- **Реактивные эффекты** — карты, которые триггерятся при действиях противника
- **Блокировка ходов/ходов противника** — манипуляция счётчиком ходов
- **Специальные паттерны** — крест, кольцо, другие формы помимо ромба
- **Условные эффекты** — карты, мощность которых зависит от состояния доски
