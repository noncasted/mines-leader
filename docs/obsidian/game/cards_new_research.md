Экспериментальные карты, расширяющие пространство дизайна за пределы текущих систем. Каждая карта требует новых механик или API — это исследовательский материал, а не план реализации.

## Подробные описания

### Dimension Rift
> Мана: 4 | Цель: OpponentBoard | Паттерн: ромб (размер 2) | Категория: Кросс-борд

Обменивает область ромба между своим полем и полем противника. Все состояния клеток переносятся: мины, флаги, открытость, эффекты. Позиция на своём поле — зеркальная относительно центра доски.

**Fit-анализ:** Принципиально новая механика, не имеющая аналогов среди текущих 22 карт. Создаёт глубокие тактические решения: можно "импортировать" безопасную область с поля противника или "экспортировать" опасную зону со своего поля. Проблема — игроку сложно просчитать последствия, особенно когда в области есть открытые клетки с числами MinesAround, которые после обмена станут некорректными. Потребуется пересчёт MinesAround для всех соседних клеток обеих досок.

**Комбо:** Sonar (отфлажить мины в своей области) -> Dimension Rift (отправить отфлаженные мины противнику). Trebuchet (заминировать вражескую область) -> Dimension Rift (забрать безопасную часть обратно).

**Новые системы:** API обмена клетками между досками. Пересчёт MinesAround для обеих досок после обмена. Синхронизация snapshot для обоих игроков одновременно. Визуализация "зеркальной" позиции на клиенте.

**Вердикт:** PASS — самая сложная карта в списке по реализации. Пересчёт MinesAround после обмена — главная техническая проблема, аналогичная причине отказа от Aftershock. Отличается тем, что здесь пересчёт неизбежен для обеих досок.

### Mirror Match
> Мана: 3 | Цель: Self | Паттерн: -- | Категория: Кросс-борд

Копирует последнюю карту, сыгранную противником, и выполняет её с теми же параметрами, но в свою пользу. Если последняя карта противника была Trebuchet на позицию (5,3) — ставит мины на поле противника на ту же позицию. Если карт ещё не сыграно — ничего не происходит.

**Fit-анализ:** Создаёт интересную "гонку вооружений": противник думает дважды перед игрой сильных карт, зная что они могут быть скопированы. Проблема — некоторые карты нельзя зеркалить осмысленно (Gravedigger копирует чей сброс? Purge снимает чьи эффекты?). Нужны правила для каждой карты: что значит "в свою пользу". Для атакующих карт (Trebuchet, Opponent Bomb) интуитивно — меняется цель. Для Self-карт — неоднозначно.

**Комбо:** Лучше всего копировать дорогие карты противника (Chain Reaction за 3 маны вместо 4, Erosion Dozer за 3 вместо 4). Poker Face блокирует Mirror Match (скрывает сыгранную карту).

**Новые системы:** История сыгранных карт с параметрами (позиция, тип). Система клонирования эффекта карты с переключением цели. Правила "зеркалирования" для каждого CardType.

**Вердикт:** PASS — элегантная идея, но правила зеркалирования для 22+ карт — большой объём дизайна. Каждая новая карта должна иметь описание "зеркального" поведения.

### Parasitic Link
> Мана: 3 | Цель: Opponent | Паттерн: -- | Длительность: 2 раунда | Категория: Кросс-борд

Устанавливает паразитическую связь с противником. Когда противник играет карту в следующие 2 раунда, вы получаете ослабленную версию эффекта (50% размера области, округление вниз). Действует на все карты противника до истечения.

**Fit-анализ:** Уникальная механика — заставляет противника "делиться" эффектами. Противник оказывается в ситуации, где любая карта частично помогает вам. Лучший контрплей — играть дешёвые слабые карты или пережидать 2 раунда. Сложность: масштабирование "50% размера" для карт без размера (Overclock дает +1 вместо +2? Scavenger даёт 1 карту вместо 2?). Нужны правила для каждого типа карты.

**Комбо:** Lockdown + Parasitic Link — противник ограничен в ходах и при этом делится эффектами. Purge не поможет — Parasitic Link висит на противнике, а не на вашем поле.

**Новые системы:** Хуки на событие "противник сыграл карту". Система масштабирования эффектов (50% от каждого параметра). Модификатор на игроке с отслеживанием оставшихся раундов.

**Вердикт:** PASS — интересная стратегическая карта, но масштабирование эффектов потребует индивидуальных правил для каждой карты. Высокая стоимость поддержки при добавлении новых карт.

### Tectonic Shift
> Мана: 4 | Цель: OpponentBoard | Паттерн: строка или столбец | Категория: Кросс-борд

Сдвигает целую строку или столбец поля противника на 1 позицию (с заворачиванием: клетка, вышедшая за край, появляется с другой стороны). Мины, флаги, открытость — всё перемещается. Игрок выбирает строку/столбец и направление.

**Fit-анализ:** Мощная дизруптивная карта, буквально "землетрясение". Ломает все паттерны флагов, смещает мины относительно открытых чисел. Проблема та же, что у Dimension Rift и Aftershock: MinesAround соседних клеток становятся некорректными после сдвига. На поле 16x16 одна строка — 16 клеток, и у каждой до 8 соседей, многие из которых в соседних строках. Каскадный пересчёт неизбежен.

**Комбо:** Tectonic Shift -> Opponent Bomb (числа сбиты, противник не может безопасно открывать). Fog of War + Tectonic Shift — противник теряет и числа, и позиционную информацию.

**Новые системы:** API сдвига строки/столбца с заворачиванием. Полный пересчёт MinesAround для затронутых клеток. UI выбора строки/столбца (новый тип таргетинга, не позиция). Анимация сдвига на клиенте.

**Вердикт:** PASS — визуально эффектная карта, но пересчёт MinesAround после сдвига делает реализацию очень сложной. Новый тип таргетинга (строка/столбец вместо позиции) требует доработки UI.

### Mind Read
> Мана: 2 | Цель: Opponent | Паттерн: -- | Длительность: 2 раунда | Категория: Информация

Показывает руку противника на 2 раунда. Вы видите все карты в руке противника (названия и стоимость маны) в отдельном UI-блоке.

**Fit-анализ:** Чистая информационная карта — дешёвая (2 маны), не влияет на доску, но даёт огромное стратегическое преимущество. Зная руку противника, можно предугадать его действия: видите Trebuchet — ставите Purge/Sonar заранее. Видите Medic при низком HP — знаете, что противник будет оборонятся. Хорошо вписывается в категорию "информация", которая сейчас пустая (Smoke/Fog — анти-информация, а про-информации нет). Низкая мана оправдана: карта не меняет состояние игры напрямую.

**Комбо:** Mind Read -> Hand Scramble (увидеть руку, потом рерольнуть если опасная). Mind Read + Lockdown (знать план противника и ограничить его ходы).

**Новые системы:** API видимости руки противника (сейчас рука приватна). Клиентский UI для отображения чужой руки (новый блок интерфейса). Модификатор на игроке "HandRevealed" с длительностью.

**Вердикт:** PASS — одна из самых простых карт в списке по реализации. Не затрагивает доску, не требует пересчётов. Основная работа — клиентский UI и протокол передачи данных руки.

### Poker Face
> Мана: 1 | Цель: Self | Паттерн: -- | Длительность: 2 раунда | Категория: Информация

Скрывает вашу руку от эффектов Mind Read и прячет названия ваших сыгранных карт — противник видит только "Карта использована" вместо конкретного названия. Длится 2 раунда.

**Fit-анализ:** Дешёвая контр-карта (1 мана), имеет смысл только при наличии Mind Read или Mirror Match в мете. Без них — бесполезна. Это типичный "tech card" из CCG: берёшь в колоду, если часто встречаешь конкретную угрозу. Проблема — если Mind Read не популярна, Poker Face занимает слот в колоде впустую. Скрытие названий карт — побочный бонус, полезный против Mirror Match.

**Комбо:** Контрит Mind Read и Mirror Match напрямую. Вместе с Parasitic Link бесполезна (Parasitic Link триггерится на факт игры карты, а не на знание какой именно).

**Новые системы:** Флаг видимости "card play" для игрока. Модификация протокола: при PokerFace активном, в сетевом сообщении о сыгранной карте заменять CardType на скрытый тип. Клиентский UI: "Карта использована" вместо названия.

**Вердикт:** PASS — технически простая, но зависит от наличия карт, которые она контрит. Имеет смысл добавлять только в паре с Mind Read/Mirror Match.

### Intelligence Report
> Мана: 3 | Цель: Self | Паттерн: -- | Категория: Информация

Показывает тепловую карту вероятностей мин на вашем поле. На каждой закрытой клетке отображается процент вероятности наличия мины, рассчитанный на основе открытых чисел. Overlay держится до конца хода.

**Fit-анализ:** "Pay-to-think" карта — тратишь ману и действие, чтобы получить анализ, который теоретически можно сделать в голове. Отличие — алгоритм учитывает все ограничения одновременно (constraint satisfaction), что человеку сложно. Этичный вопрос: это по сути встроенный "читерский" солвер за ману. С другой стороны, мана и действие — это реальная цена, и противник может сломать анализ Trebuchet'ом (добавив мины). Для соревновательной игры спорно: уравнивает скилл-гэп между новичками и экспертами.

**Комбо:** Intelligence Report -> Zip Zap / Bloodhound (точно знаешь куда бить). Intelligence Report + Sonar (подтвердить подозрения и поставить флаги).

**Новые системы:** Алгоритм расчёта вероятностей мин (constraint satisfaction solver — нетривиальная математика). Overlay UI на доске с процентами. Система heatmap-рендеринга на клиенте (цветовая градация клеток).

**Вердикт:** PASS — самая спорная карта с точки зрения гейм-дизайна. Солвер мин — это или "too powerful" или "pay-to-win thinking". Технически сложная: constraint satisfaction на 16x16 с 40 минами — дорогая операция.

### False Numbers
> Мана: 3 | Цель: OpponentBoard | Паттерн: ромб (размер 3) | Длительность: 2 раунда | Категория: Информация

Заменяет реальные значения MinesAround на случайные числа (1-4) на открытых клетках в области. Противник видит фальшивые числа 2 раунда. Тяжелее контрить чем Fog of War: при Fog видно, что информация скрыта; при False Numbers непонятно, какие числа настоящие.

**Fit-анализ:** Развитие идеи Fog of War, но злее. Fog честно говорит "тут нет информации". False Numbers врёт — и это опаснее, потому что противник может принять решение на основе фальшивых данных. Риск — слишком фрустрирующая механика: подрыв на мине из-за ложного числа ощущается как "нечестная смерть". Нужен визуальный индикатор, что в области False Numbers активен (иначе вообще невозможно играть). Текущий CellEffectType поддерживает Smoke и Fog — добавление FalseNumbers потребует хранения подменённого значения в эффекте.

**Комбо:** False Numbers + Trebuchet (подменить числа, потом добавить мин — противник не может пересчитать). Smoke -> False Numbers (сначала скрыть, потом подменить — двойной удар по информации). Purge снимает эффект.

**Новые системы:** Расширение CellEffectType: FalseNumbers с хранением подменённого значения (сейчас эффекты не хранят данные). Per-cell number override в рендеринге клиента. Генерация "правдоподобных" случайных чисел (чтобы сумма не была абсурдной).

**Вердикт:** PASS — сильная концепция, но фрустрация от "нечестной смерти" может быть проблемой. Требует расширения системы эффектов для хранения данных в эффекте.

### Time Bomb
> Мана: 2 | Цель: OpponentBoard | Паттерн: 1 клетка | Длительность: 3 раунда | Категория: Триггер

Размещает невидимую бомбу на закрытой клетке противника. Если противник откроет эту клетку в течение 3 раундов — получает 2 урона (вместо 0 за безопасную клетку). Если на клетке мина — 3 урона суммарно (1 за мину + 2 за бомбу). Бомба невидима для противника. После 3 раундов исчезает.

**Fit-анализ:** Первая настоящая "ловушка" в игре. Tripwire был отклонён за сложность, но Time Bomb проще: один триггер на одну клетку, не требует отслеживания "какая карта затронула клетку". Проблема из Tripwire частично остаётся: как показать игроку, что бомба поставлена, не показывая противнику? Решение — показывать ставящему игроку маркер, а противнику ничего. Дешёвая (2 маны) но рискованная: противник может не открыть эту клетку 3 раунда.

**Комбо:** Time Bomb + Bloodhound-на-вражеском-поле (невозможно, Bloodhound — OwnBoard). Time Bomb на клетку, потом Opponent Bomb на соседнюю — заставить противника открывать в том районе. Smoke + Time Bomb — скрыть область, где стоит бомба.

**Новые системы:** Отложенный триггер на событие "клетка открыта" (CellOpenedHook). Невидимый маркер на клетке (видимый только владельцу). Система урона от триггера (сейчас урон только от мин). Таймер истечения на клеточном уровне.

**Вердикт:** PASS — проще Tripwire, но всё равно требует системы триггеров на открытие клеток, которой сейчас нет. Невидимость для противника — отдельная задача для клиента.

### Echo
> Мана: 2 | Цель: Self | Паттерн: -- | Категория: Триггер

Следующая карта, сыгранная в этом ходу, автоматически повторяется в начале вашего следующего хода с теми же параметрами (та же позиция, та же цель). Echo расходуется после одного повтора.

**Fit-анализ:** Мощный усилитель, превращающий любую карту в "двойную". Echo + Trebuchet = два Trebuchet за разницу в 2 маны. Echo + Overclock = +2 хода в этом ходу и +2 в следующем. Баланс: ману за Echo платишь сейчас, но повтор бесплатный — это отложенная ценность. Проблема: что если позиция повтора стала невалидной (клетка уже открыта)? Нужны правила для каждой карты, что происходит при невалидном повторе.

**Комбо:** Echo + Trebuchet (двойной залп мин). Echo + Scavenger (4 карты за 2 хода). Echo + Lockdown (4 раунда ограничения вместо 2). Echo + Bloodhound (двойная очистка одной области).

**Новые системы:** Очередь отложенного воспроизведения карт (CardReplayQueue). Сериализация параметров карты (позиция, цель) для хранения между ходами. Логика исполнения отложенной карты в начале хода (до основной фазы). Обработка невалидных повторов.

**Вердикт:** PASS — элегантная механика с широким комбо-потенциалом. Сериализация параметров карты для отложенного исполнения — новая система, но технически не слишком сложная.

### Sleeper Agent
> Мана: 3 | Цель: OpponentBoard | Паттерн: 1 клетка | Категория: Триггер

Помечает закрытую клетку на поле противника. Когда противник ставит флаг на эту клетку, флаг тихо снимается через 1 раунд. Эффект сохраняется до тех пор, пока клетка не будет открыта или пока противник не поставит флаг (и он будет снят). Одноразовый триггер.

**Fit-анализ:** Тонкая карта-саботаж. Противник думает, что поставил флаг на мину, но через раунд флаг исчезает — и он может открыть "уже отфлаженную" клетку, не заметив, что флага нет. Психологическое оружие. Проблема — очень ситуативная: противник может никогда не флажить именно эту клетку. Сильна только если вы знаете, где мины на поле противника (чего обычно не знаете). Слабее аналогов (Flag Erase за те же 3 маны убирает флаги гарантированно).

**Комбо:** Mind Read (узнать план противника) + Sleeper Agent (поставить на клетку, которую он собирается флажить). Практически — слишком много условий для срабатывания.

**Новые системы:** Хук на событие "игрок поставил флаг" (FlagPlacedHook). Невидимый персистентный маркер на клетке. Отложенное снятие флага через 1 раунд. Таймер на уровне конкретной клетки.

**Вердикт:** PASS — красивая идея, но слишком ситуативная. Flag Erase решает ту же задачу надёжнее. Имеет смысл только если хуки на флаги уже реализованы для других целей.

### Curse
> Мана: 3 | Цель: Opponent | Паттерн: -- | Длительность: 3 раунда | Категория: Триггер

Проклинает противника на 3 раунда. Каждый подрыв на мине наносит 2 урона вместо 1. Усиливает риск для противника при открытии клеток.

**Fit-анализ:** Простая и понятная карта-усилитель урона. Не делает ничего сама по себе — усиливает существующую механику (подрыв на минах). Хорошо работает в агрессивных колодах: Curse + Trebuchet (добавить мин, потом двойной урон за них). При 3 HP противника и Curse активном, две мины = смерть вместо трёх. Проблема: противник может просто играть осторожнее 3 раунда и не открывать клетки, что замедляет игру.

**Комбо:** Curse + Trebuchet (добавить мины + удвоить урон). Curse + Chain Reaction (каскадный двойной урон). Curse + Opponent Bomb (2 урона за мину вместо 1). Medic контрит урон, Purge не поможет (Curse на противнике, не на поле).

**Новые системы:** Модификатор урона на игроке (DamageMultiplier). Хук на событие "игрок получил урон от мины" для применения модификатора. Отображение проклятия в UI противника.

**Вердикт:** PASS — одна из самых простых в реализации среди триггерных карт. Модификатор урона — полезная система, которая пригодится и для других карт (Adaptive Armor, Soul Link).

### Minefield
> Мана: 4 | Цель: OwnBoard | Паттерн: ромб (размер 3) | Длительность: 2 раунда | Категория: Зоны

Создаёт "опасную зону" на своём поле. Карты противника, нацеленные на эту область, имеют 50% шанс вместо этого применить эффект к полю противника (backfire). Длится 2 раунда. Визуально отмечается на поле.

**Fit-анализ:** Единственная "защитная зона" в игре. Текущая проблема Mirror Wall (отклонена) была в том, что щит на малой области бесполезен. Minefield решает это иначе: не блокирует, а создаёт риск. Противник МОЖЕТ атаковать зону, но с 50% шанс получить свой же эффект. Это интереснее чем "нельзя": создаёт gambling decision для противника. Проблема — 50% рандом в соревновательной игре может фрустрировать.

**Комбо:** Minefield + Sonar (защитить область, где уже поставили флаги). Minefield на область с минами — противник рискует Opponent Bomb'ом, который может backfire'нуть.

**Новые системы:** Зона на поле с длительностью (Area + Duration + Effect). Перехват таргетинга карты противника и проверка пересечения с зонами. Система "backfire" — перенаправление эффекта карты на поле владельца. RNG с визуализацией результата для обоих игроков.

**Вердикт:** PASS — решает проблему Mirror Wall, но вводит RNG в соревновательную игру. Система зон с перехватом карт — масштабная новая архитектура.

### Warp Gate
> Мана: 3 | Цель: OwnBoard + OpponentBoard | Паттерн: 2 позиции (по одной на каждом поле) | Категория: Зоны

Связывает две клетки — одну на вашем поле, одну на поле противника. Когда любая из них открывается, вторая тоже открывается автоматически. Связь действует до открытия одной из клеток.

**Fit-анализ:** Кросс-бордовый портал с элементом mutual risk. Если поставить свой конец на безопасную клетку, а чужой на подозрительную — при открытии противником своей клетки вы безопасно откроете свою. Но если противник откроет вашу клетку — откроется и его. Новый тип таргетинга: нужно выбрать две позиции на разных досках. Проблема — сложная логика: что если клетка с миной? Кто получает урон?

**Комбо:** Warp Gate (ваш конец на безопасную клетку) + ждать пока противник откроет свою связанную клетку. Time Bomb + Warp Gate (бомба на одном конце, портал открывает её когда противник активирует другой конец).

**Новые системы:** Связывание клеток между досками (CrossBoardCellLink). Двойной таргетинг (выбор позиции на обеих досках — новый UI-паттерн). Обработка каскадного открытия через связь. Правила урона при кросс-бордовом открытии мины.

**Вердикт:** PASS — оригинальная механика, но двойной таргетинг и кросс-бордовая связь — значительная доработка UI и протокола. Правила для edge cases (мина, эффекты, flood-fill через портал) требуют проработки.

### Dead Zone
> Мана: 3 | Цель: OpponentBoard | Паттерн: ромб (размер 2) | Длительность: 2 раунда | Категория: Зоны

Создаёт зону на поле противника, в которой ни один из игроков не может играть карты в течение 2 раундов. Клетки в зоне также нельзя открывать или флажить. Полная блокировка области.

**Fit-анализ:** True area denial — замораживает часть доски. Полезна для защиты территории, которую вы уже заминировали (Trebuchet -> Dead Zone = мины, которые нельзя обезвредить 2 раунда). Размер ромба 2 — маленький (7 клеток), но на плотно открытом поле это критично. Проблема — блокировка открытия клеток ломает основной gameplay loop. Противник не может играть в этой области вообще, что может ощущаться как "stolen turns".

**Комбо:** Trebuchet + Dead Zone (заминировать область и запечатать). Chain Reaction + Dead Zone (мины в области нельзя обезвредить). Smoke + Dead Zone — разные функции: Smoke скрывает но не блокирует, Dead Zone блокирует но не скрывает.

**Новые системы:** Per-cell restriction на действия (открытие, флаг, таргет карты). Проверка ограничений при каждом действии игрока. Визуализация "запрещённой зоны" на клиенте. Валидация таргетинга карт с учётом Dead Zone.

**Вердикт:** PASS — концептуально простая зона-блокировка, но проверка ограничений при каждом действии — проникающее изменение во всей системе действий.

### Card Thief
> Мана: 3 | Цель: Opponent | Паттерн: -- | Категория: Колода

Крадёт 1 случайную карту из руки противника. Карта переходит в вашу руку (работает даже если рука полная — сверх лимита). Противник теряет карту до конца текущего цикла колоды.

**Fit-анализ:** Прямая агрессия против руки противника — сильнее Hand Scramble, потому что карта не возвращается в колоду, а переходит к вам. Создаёт уникальную ситуацию: вы можете играть карту, которой нет в вашей колоде. Главная проблема — что делать с чужой картой? Она может быть Max-версией, которой у вас нет. Нужна система "иностранных карт" в руке. Баланс: за 3 маны вы лишаете противника ресурса И получаете его — swing value очень высокий.

**Комбо:** Card Thief + Hand Scramble (украсть лучшую, потом перемешать остальное). Card Thief -> сыграть украденную карту в тот же ход (если хватит маны и действий).

**Новые системы:** Кросс-игроковой трансфер карт (CardTransfer API). Система "иностранных карт" в руке (карта с чужим CardType). Исполнение украденной карты от лица нового владельца. UI отображения "чужой" карты в руке.

**Вердикт:** PASS — мощная концепция, но "иностранная карта" в руке — архитектурно сложная проблема. Сейчас карты привязаны к колоде игрока; трансфер ломает эту инвариант.

### Sabotage Deck
> Мана: 2 | Цель: Opponent | Паттерн: -- | Категория: Колода

Подмешивает карту-пустышку (Dud) в колоду противника. Dud не делает ничего при вытягивании и при игре: тратит действие и ману, но без эффекта. Пустышка остаётся в колоде до конца игры (попадает в сброс и возвращается при перемешивании).

**Fit-анализ:** Тонкий саботаж — не мгновенный, а отложенный. Противник когда-нибудь вытянет пустышку и потеряет слот в руке + действие + ману, если попытается сыграть. Слабость: дешёвая карта (2 маны), но эффект может проявиться через много раундов. Множественное использование Sabotage Deck кумулятивно засоряет колоду. Проблема: нужен новый CardType (Dud), и противник должен видеть, что это пустышка (иначе он каждый раз тратит ману впустую — слишком жёстко).

**Комбо:** Sabotage Deck x2-3 = 2-3 пустышки в колоде из 10 = 20-30% шанс вытянуть мусор. Hand Scramble + Sabotage Deck (рерольнуть руку + засорить колоду).

**Новые системы:** Новый CardType: Dud (нулевой эффект, визуально отличается). API вставки карты в чужую колоду (CrossDeckInsert). Логика: Dud попадает в сброс после игры и возвращается при перетасовке.

**Вердикт:** PASS — элегантная и технически не слишком сложная карта. Основная работа — новый CardType и API вставки в чужую колоду. Баланс: противник должен видеть что это Dud, иначе слишком фрустрирующе.

### Power Surge
> Мана: 3 | Цель: Self | Паттерн: -- | Длительность: 1 ход | Категория: Колода

Все ваши карты стоят на 1 ману меньше в этом ходу (минимум 1). Действует только на оставшиеся розыгрыши в текущем ходу.

**Fit-анализ:** Экономическая карта-усилитель. За 3 маны вы получаете скидку на все последующие карты в ходу. Окупается если играете 3+ карты после Power Surge (3 x 1 мана скидки = 3 маны экономии). Проблема — при лимите 5 ходов и 5 картах в руке, реально сыграть 4 карты после Power Surge только с Overclock. Без Overclock — 4 хода на карты (1 потрачен на Power Surge), экономия максимум 4 маны. С Overclock — 6 ходов, экономия до 6 маны. Сильная комбо-карта, слабая сама по себе.

**Комбо:** Power Surge + Overclock (7 ходов, все карты дешевле — взрывной turn). Power Surge + Scavenger (добрать карты по скидке, сыграть добранные тоже со скидкой). Power Surge + Blood Pact (0 мана за Blood Pact и так, но +3 маны от Blood Pact + скидка от Surge = огромный поток ресурсов).

**Новые системы:** Модификатор стоимости карт на уровне хода (TurnScopedCostModifier). Пересчёт стоимости карт в руке при активации модификатора. UI обновление стоимости карт в руке в реальном времени.

**Вердикт:** PASS — технически простая система (модификатор на ход), но требует динамического пересчёта стоимости карт в UI. Хорошая комбо-карта для Overclock-колод.

### Evolution
> Мана: 4 | Цель: Self | Паттерн: -- | Категория: Колода

Перманентно улучшает 1 карту в руке до _Max версии на всю оставшуюся игру. Игрок выбирает какую карту улучшить. Если карта уже Max — вместо этого берёте 1 карту из колоды.

**Fit-анализ:** Уникальная перманентная инвестиция. За 4 маны вы получаете усиленную карту на всю игру — ценность растёт с каждым использованием. Лучше всего улучшать часто используемые карты: Bloodhound_Max / Zip Zap_Max / Trebuchet_Max. Проблема: сейчас _Max версии — это отдельные CardType с другими параметрами. "Замена" карты в колоде на Max-версию требует модификации колоды на лету.

**Комбо:** Evolution + Gravedigger (улучшить Gravedigger, потом возвращать улучшенные карты из сброса). Evolution на Trebuchet = Trebuchet_Max на всю игру. Scavenger -> Evolution (добрать карты, выбрать лучшую для улучшения).

**Новые системы:** API замены карты в колоде на другой CardType (CardUpgrade). Маппинг Base -> Max для всех карт. UI выбора карты из руки для улучшения (новый тип таргетинга: выбор карты, не позиции). Персистентная модификация колоды (сейчас колода фиксирована на игру).

**Вердикт:** PASS — сильная идея для long-game стратегий. Новый тип таргетинга (выбор карты из руки) и модификация колоды — две новые системы, но обе полезны для будущих карт.

### Gambler's Ruin
> Мана: 2 | Цель: Self | Паттерн: -- | Категория: Риск

Бросок монеты. Орёл: берёте 3 карты из колоды + получаете 2 временной маны. Решка: сбрасываете 2 случайные карты из руки. Высокая дисперсия.

**Fit-анализ:** Первая карта с чистым RNG-исходом. В соревновательных играх такие карты спорны: про-игроки не любят случайность, казуалы — любят. За 2 маны это либо +3 карты +2 маны (огромный swing, лучше Scavenger), либо -2 карты (катастрофа, потеря темпа). Математически: EV = 0.5 * (3 карты + 2 маны) + 0.5 * (-2 карты) = сильно положительный, но с огромным разбросом.

**Комбо:** Gambler's Ruin при пустой руке — нечего терять, можно только выиграть. Echo + Gambler's Ruin (два броска — вероятность хотя бы одного орла = 75%). Gravedigger -> Gambler's Ruin (вернуть из сброса и рискнуть).

**Новые системы:** RNG-система с визуализацией (анимация броска монеты на клиенте). Ветвление эффекта карты по результату RNG. Временная мана (TempMana — исчезает в конце хода). Принудительный сброс случайных карт из руки.

**Вердикт:** PASS — технически несложная, но вопрос гейм-дизайна: допустим ли чистый RNG в соревновательной игре? Временная мана — полезная новая система.

### Overcharge
> Мана: 0 (переменная) | Цель: Self | Паттерн: -- | Категория: Риск

Тратит ВСЮ текущую ману. Наносит урон противнику = потраченная мана / 3 (округление вниз). Нужно минимум 3 маны для хотя бы 1 урона. После Overcharge у вас 0 маны до конца хода.

**Fit-анализ:** Конвертация ресурса (мана) в другой (урон). Уникальная "финишер"-карта: при 9 мане = 3 урона = мгновенная смерть противника с полным HP. Проблема — накопить 9 маны очень сложно (мана = номер хода, максимум ~8-10 к поздней игре, минус траты). Реалистично: 6 маны = 2 урона за всю ману — хороший финиш при HP 1-2 у противника. Стоимость 0 маны обманчива: реальная стоимость = вся ваша мана.

**Комбо:** Siphon (поднять макс. ману) -> копить -> Overcharge (больше маны = больше урона). Blood Pact (0 маны) + Overcharge (сначала Blood Pact даёт +3 маны, потом Overcharge тратит всё). Power Surge бесполезен с Overcharge (Overcharge стоит 0).

**Новые системы:** Карта с переменной стоимостью (тратит всю ману вместо фиксированной цены). Прямой урон от карты без привязки к доске. UI отображения "потенциального урона" при наведении (зависит от текущей маны).

**Вердикт:** PASS — элегантный финишер. Карта с переменной стоимостью — новая концепция, но реализуемая расширением `Mana.Use()`. Баланс критичен: слишком сильна в лейте.

### Blood Pact
> Мана: 0 | Цель: Self | Паттерн: -- | Категория: Риск

Теряете 1 HP. Получаете +3 временной маны и +2 дополнительных действия в этом ходу. Жертва здоровья ради взрывного хода.

**Fit-анализ:** Агрессивная карта с жёсткой платой. При 3 HP: одно использование оставляет 2 HP, два — 1 HP. Взамен получаете почти полный дополнительный ход (+3 маны +2 действия). По сути это Overclock (3 маны, +2 действия) + 3 маны бонус, но ценой 1 HP вместо 3 маны. Опасна при низком HP — нельзя использовать при 1 HP (иначе самоубийство, нужна проверка).

**Комбо:** Blood Pact + Overcharge (потерять HP, получить ману, потратить всю ману на урон). Blood Pact + Medic (потерять HP, потом вылечить — нет, Medic стоит 4 маны и действие). Blood Pact + Power Surge + несколько карт (взрывной комбо-ход). Blood Pact + Trebuchet + Chain Reaction (один агрессивный ход).

**Новые системы:** Самоурон как стоимость карты (SelfDamage). Проверка: нельзя играть при 1 HP (минимальный порог). Временная мана (+3 temp mana, исчезает в конце хода). Комбинация с Overclock: +2 действия от Blood Pact стакаются.

**Вердикт:** PASS — сильная design space: HP как ресурс для размена. Проверка минимального HP и временная мана — нужные, но несложные системы.

### Chaos Theory
> Мана: 4 | Цель: Self | Паттерн: -- | Категория: Риск

Случайно выбирает и исполняет эффект любой карты из полного пула (включая карты, которых нет в вашей колоде). Позиция выбирается случайно (для карт с таргетингом). Непредсказуемый результат.

**Fit-анализ:** Максимальный хаос. За 4 маны вы получаете случайный эффект из ~22 карт. Может сработать как Trebuchet на поле противника (отлично) или как Opponent Bomb на случайную клетку (мимо). Проблема — некоторые эффекты вредят при случайной позиции: Bloodhound на случайную позицию может открыть мины, Smoke на своём поле бессмысленен. Нужны правила "от чьего лица" исполнять каждую карту.

**Комбо:** Нет контролируемых комбо — в этом суть карты. Echo + Chaos Theory = два случайных эффекта (безумие). Poker Face скрывает факт использования Chaos Theory от противника.

**Новые системы:** Глобальный пул всех карт с возможностью случайного выбора. Случайная генерация валидных параметров для каждого типа карты (случайная позиция на правильном поле). Система "исполнения от лица" — маппинг Self/Opponent карт к текущему игроку.

**Вердикт:** PASS — "fun" карта для казуального режима, но проблемная для соревновательного. Глобальный пул и случайная параметризация — масштабная система.

### Soul Link
> Мана: 3 | Цель: Opponent | Паттерн: -- | Длительность: 2 раунда | Категория: Ресурсы

Связывает вас с противником на 2 раунда. Когда вы получаете урон от мины, противник тоже получает 1 урон. Mutual assured destruction.

**Fit-анализ:** Рискованная защитная карта. Не защищает от мин, но создаёт "ядерное сдерживание": противник знает, что ваш подрыв навредит и ему. Изменяет стратегию противника — он не хочет провоцировать вас открывать опасные клетки (например, через Opponent Bomb). Но вы тоже рискуете: если откроете мину, получите 1 урон + противник получит 1 урон — суммарный damage одинаковый. Полезна когда у вас больше HP чем у противника.

**Комбо:** Soul Link + Blood Pact (Blood Pact наносит самоурон — триггерится ли Soul Link? Нужно решение: самоурон от карт НЕ триггерит, только урон от мин). Soul Link + Phase Shift (вы защищены от мин, но Soul Link всё равно не триггерится — нет урона). Curse на вас + Soul Link = ваши мины наносят 2 урона вам и 1 противнику — плохо.

**Новые системы:** Хук на событие "игрок получил урон от мины" (MineDamageHook). Отражение урона на другого игрока. Различение типов урона (от мин vs от карт vs самоурон) — нужно для корректной работы. UI индикация активной связи.

**Вердикт:** PASS — интересная стратегическая глубина, но требует системы типизации урона (от мин / от карт / самоурон), что полезно и для Curse, и для Adaptive Armor.

---

### Terraform
> Мана: 4 | Цель: OwnBoard | Паттерн: 1 клетка | Категория: Ресурсы

Перманентно удаляет 1 мину с целевой закрытой клетки на своём поле. Мина исчезает (не перемещается). Общее число мин на поле уменьшается на 1. MinesAround соседних клеток пересчитывается.

**Fit-анализ:** Единственная карта, которая уменьшает число мин на поле. Мощная, но требует знания, где мина — без флагов или Sonar нужно угадывать. При ошибке (клетка без мины) — карта потрачена впустую. Цена 4 маны оправдана: перманентное удаление мины упрощает поле навсегда. Проблема — пересчёт MinesAround для всех соседних FreeCell. Это та же проблема что у Aftershock, но масштабом в 1 клетку: нужно обновить до 8 соседей, что вычислительно тривиально.

**Комбо:** Sonar (найти мины) -> Terraform (удалить самую опасную). Intelligence Report -> Terraform (знаешь где мины — удаляешь). Zip Zap vs Terraform: Zip Zap уничтожает до 3 мин за 3 маны, Terraform — 1 за 4. Но Terraform не требует открытия, а Zip Zap — обезвреживает.

**Новые системы:** API удаления мины с пересчётом MinesAround (MineRemoval). Обновление board mine count (сейчас фиксирован на 40). Пересчёт MinesAround для 8 соседей (ограниченный, не каскадный). Валидация: клетка должна быть closed и с миной.

**Вердикт:** PASS — мощная карта. Пересчёт MinesAround для 1 клетки решаем (в отличие от массового пересчёта Aftershock). Mine count adjustment — новый, но простой.

---

### Phase Shift
> Мана: 3 | Цель: Self | Паттерн: -- | Длительность: 1 раунд | Категория: Ресурсы

Все мины на вашем поле становятся "фазированными" на 1 раунд. Открытие клетки с фазированной миной не детонирует — клетка открывается как обычная (TakenCell -> FreeCell с пересчётом). Фактически: 1 раунд безопасного открытия любых клеток.

**Fit-анализ:** Чрезвычайно мощная карта — полная безопасность на 1 раунд. При 5 ходах можно открыть 5 клеток без риска, даже если все 5 — мины. Это переворачивает суть игры: мины перестают быть угрозой. Баланс: 1 раунд — это мало (5 ходов), и 3 маны — средняя цена. Но в комбинации с Overclock (7 ходов безопасного открытия) — потенциально game-breaking. Нужен лимит: Phase Shift НЕ стакается с Overclock? Или увеличить ману до 5?

**Комбо:** Phase Shift + Overclock (7 безопасных открытий — огромный прогресс). Phase Shift + открытие подозрительных клеток без флагов. Phase Shift обесценивает Trebuchet (мины не опасны 1 раунд). Curse + Phase Shift = Curse не триггерится (нет урона от мин).

**Новые системы:** Флаг подавления детонации мин (MineDetonationSuppressed). Модификация логики открытия клетки: если suppressed, TakenCell с миной -> FreeCell (пересчёт MinesAround). Обработка "открытой мины" визуально (анимация обезвреживания?).

**Вердикт:** PASS — design-wise рискованная карта. "Безопасный раунд" может быть слишком сильным. Подавление детонации — несложная система (один флаг), но пересчёт MinesAround при открытии мины без детонации — новая логика.

---

### Mana Crystal
> Мана: 3 | Цель: OwnBoard | Паттерн: 1 клетка | Категория: Ресурсы

Размещает кристалл на закрытой клетке своего поля. Когда вы открываете эту клетку: если нет мины — получаете +2 к перманентному максимуму маны. Если мина — кристалл уничтожается, мина детонирует как обычно. Кристалл видим обоим игрокам.

**Fit-анализ:** Инвестиция с риском. За 3 маны + 1 действие вы ставите ставку: если клетка безопасна (и вы это знаете через Sonar/числа), получаете +2 макс. маны навсегда — лучше чем Siphon (+1 мана за 2). Если не уверены — рискуете потерять 3 маны + 1 HP. Кристалл видим обоим — противник может попытаться заминировать эту клетку (Trebuchet?) до того, как вы откроете. Но Trebuchet не может точно попасть в одну клетку. Интересная динамика "защиты кристалла".

**Комбо:** Sonar -> Mana Crystal (убедиться что клетка безопасна, потом поставить кристалл). Intelligence Report -> Mana Crystal (поставить на клетку с 0% вероятностью мины). Mana Crystal + Siphon (двойное увеличение маны — доминирование в ресурсах). Противник: Trebuchet рядом с кристаллом (добавить мины в область).

**Новые системы:** Персистентный токен на клетке (CellToken — видимый объект, не эффект). Хук на открытие клетки с токеном. Модификация макс. маны как награда. Визуализация кристалла на клиенте (новый спрайт/элемент).

**Вердикт:** PASS — одна из лучших карт в списке по игровому дизайну. Токены на клетках — новая система, но масштабируемая (можно использовать для Time Bomb, Sleeper Agent и др.).

---

### Shared Vision
> Мана: 4 | Цель: Self | Паттерн: -- | Длительность: 1 раунд | Категория: Мета

Оба игрока видят полностью оба поля на 1 раунд. Все закрытые клетки показываются прозрачно (overlay): мины подсвечены, безопасные клетки отмечены. Информация симметрична — вы видите поле противника, противник видит ваше.

**Fit-анализ:** "Ядерный вариант" информационной войны. Полная прозрачность на 1 раунд даёт обоим игрокам полную информацию. Вы можете открыть все безопасные клетки, но противник — тоже. Полезна когда вы впереди по открытым клеткам (опережение сохраняется, но оба игрока прогрессируют). Проблема — при 4 мане и 5 ходах, 1 раунд полной видимости может решить игру: оба игрока открывают всё безопасное, остаются только мины.

**Комбо:** Shared Vision + Trebuchet (видите поле противника, точно знаете куда ставить мины). Shared Vision + Terraform (видите свои мины, удаляете самую опасную). Lockdown + Shared Vision (противник видит всё, но ограничен в ходах — не может воспользоваться).

**Новые системы:** Полный overlay обоих полей (рендеринг "скрытого" слоя поверх закрытых клеток). Протокол передачи полного состояния обоих полей обоим клиентам (сейчас каждый видит только своё). Модификатор видимости на уровне игры (не конкретного поля).

**Вердикт:** PASS — мощная симметричная карта, но рискует "сломать" раунд. Передача полного состояния обоих полей обоим клиентам — серьёзное изменение протокола.

---

### Duel
> Мана: 3 | Цель: Opponent | Паттерн: -- | Категория: Мета

Оба игрока одновременно открывают 1 случайную закрытую клетку на СВОЁМ поле. Если кто-то попадает на мину — получает урон. Обоюдный риск. Не потребляет ходы (дуэль — отдельное действие).

**Fit-анализ:** Чистая "рулетка" с взаимным риском. При 40 минах на 256 клеток (16x16), вероятность мины ~15.6% в начале. К середине, когда открыто 100 клеток, вероятность ~25.6%. Оба игрока рискуют одинаково — симметричная механика. Полезна когда у вас больше HP: вы "можете себе позволить" дуэль. Проблема — не потребляет ходы, т.е. это "бесплатное" открытие (за 3 маны). Случайность может фрустрировать.

**Комбо:** Curse + Duel (если противник попадёт на мину — 2 урона вместо 1). Soul Link + Duel (если вы попадёте на мину — противник тоже получит урон, "дополнительное сдерживание"). Phase Shift + Duel (вы неуязвимы к минам — безопасная дуэль для вас).

**Новые системы:** Одновременное действие для обоих игроков (SimultaneousAction). Случайный выбор закрытой клетки на каждом поле. Разрешение одновременного урона (оба могут умереть — ничья?). Анимация дуэли на клиенте.

**Вердикт:** PASS — простая концепция, но "одновременное действие" — новый паттерн для пошаговой игры. Вопрос: что если оба умирают? Нужны правила для ничьей.

### Adaptive Armor
> Мана: 2 | Цель: Self | Паттерн: -- | Перманентный | Категория: Мета

Перманентный эффект. Каждый раз когда вы получаете урон от мины, все ваши карты увеличивают размер паттерна на +1 на всю оставшуюся игру. Стакается. Чем больше вы страдаете — тем сильнее становитесь.

**Fit-анализ:** "Comeback mechanic" — карта для проигрывающего игрока. При 3 HP и потере 2 HP, ваши паттерны увеличиваются на +2 (Bloodhound ромб 6 вместо 4, Trebuchet ромб 6 вместо 4). Создаёт интересную дилемму: стоит ли намеренно рисковать, чтобы усилить карты? Blood Pact + Adaptive Armor = самоурон усиливает карты (но самоурон от карт — отдельный тип, нужно решение). Проблема: при 1 HP осталось и +2 к паттернам — одна ошибка и смерть, но карты огромные.

**Комбо:** Adaptive Armor + Blood Pact (намеренный самоурон для усиления). Adaptive Armor + Overcharge (стать сильнее после урона, потом конвертировать ману в урон — разные оси усиления). Adaptive Armor + Bloodhound_Max (ромб 7+ = огромная область очистки).

**Новые системы:** Перманентный стакающийся модификатор размера паттернов на игроке (PatternSizeModifier). Хук на событие "получен урон от мины" (MineDamageHook — общий с Soul Link, Curse). Динамический пересчёт размера паттернов всех карт. UI отображение текущего бонуса.

**Вердикт:** PASS — отличная "comeback" механика, но динамический размер паттернов — проникающее изменение: каждая карта с паттерном должна читать модификатор вместо константы.

## Анализ сложности реализации

### По группам необходимых систем

| Новая система | Какие карты требуют | Сложность |
|---------------|--------------------:|-----------|
| MineDamageHook (хук на урон от мины) | Curse, Soul Link, Adaptive Armor | Средняя — одна точка хука в логике детонации |
| CellOpenedHook (хук на открытие клетки) | Time Bomb, Mana Crystal, Warp Gate | Средняя — одна точка хука в логике открытия |
| TempMana (временная мана) | Gambler's Ruin, Blood Pact | Низкая — расширение Mana системы |
| CardReplayQueue (отложенное исполнение) | Echo | Средняя — сериализация параметров + очередь |
| CrossBoardAPI (обмен между досками) | Dimension Rift, Warp Gate, Tectonic Shift | Высокая — синхронизация двух досок |
| HandVisibility (видимость руки) | Mind Read, Poker Face | Низкая — флаг + протокол |
| CellToken (токены на клетках) | Mana Crystal, Time Bomb, Sleeper Agent | Средняя — новая сущность на клетке |
| DamageModifier (модификатор урона) | Curse, Soul Link, Blood Pact | Средняя — типизация урона + модификаторы |
| PatternSizeModifier (размер паттернов) | Adaptive Armor | Средняя — динамический пересчёт для всех карт |
| MinesAroundRecalc (пересчёт чисел) | Dimension Rift, Tectonic Shift, Terraform, Phase Shift | Высокая для массового, низкая для одиночного |
| CrossDeckInteraction (кросс-колода) | Card Thief, Sabotage Deck | Высокая — ломает инвариант "колода принадлежит игроку" |
| CardCostModifier (модификатор стоимости) | Power Surge | Низкая — модификатор на ход |
| SimultaneousAction (одновременные действия) | Duel | Высокая — новый паттерн для пошаговой игры |
| FullBoardVisibility (полная видимость) | Shared Vision, Intelligence Report | Высокая — изменение протокола |
| RNGOutcome (случайные исходы) | Gambler's Ruin, Chaos Theory, Duel | Средняя — визуализация + ветвление |

### Топ-5 самых простых в реализации

1. **Mind Read** — только флаг видимости + UI блок руки противника
2. **Curse** — модификатор урона + хук на детонацию
3. **Power Surge** — модификатор стоимости на ход
4. **Blood Pact** — самоурон + временная мана + доп. ходы (всё на существующих API)
5. **Sabotage Deck** — новый CardType + вставка в колоду

### Топ-5 самых сложных в реализации

1. **Dimension Rift** — кросс-бордовый обмен + массовый пересчёт MinesAround
2. **Tectonic Shift** — сдвиг строки + массовый пересчёт + новый тип таргетинга
3. **Chaos Theory** — глобальный пул + случайная параметризация всех карт
4. **Shared Vision** — полное раскрытие обоих полей обоим клиентам
5. **Card Thief** — кросс-игроковой трансфер + исполнение чужой карты
