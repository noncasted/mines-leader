### Описание эффекта

Бросок монеты: орел — +2 карты в руку из колоды, решка — убрать 2 карты из руки обратно в колоду (случайные).

### Сложность: 3

RNG + работа с рукой/колодой. При решке: случайный выбор 2 карт для возврата. Snapshot содержит результат + затронутые карты.
