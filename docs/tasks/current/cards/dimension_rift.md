## Задача: DimensionRift — обмен областями между полями

### Статус: Не начато

### Карта

| Поле | Значение |
|------|----------|
| Имя | DimensionRift |
| Мана | 4 |
| Цель | OpponentBoard |
| Паттерн | ромб (2) |
| Категория | Кросс-борд |
| Пул | Research |
| Max-вариант | Нет |

### Описание эффекта

Обменивает области ромбом (размер 2) между вашим и полем противника. Все состояния клеток переносятся: открытые, закрытые, флажки, мины.

### Сложность: 10

Самая сложная карта: полный обмен состояния между двумя досками. Нужно: сохранить состояние области A, сохранить область B, записать A в B и B в A. Пересчет MinesAround на обеих досках. Двойной snapshot. Множество edge cases.

### Особые требования

- Полный swap состояния клеток между двумя досками — новая уникальная механика
- Пересчет MinesAround на обеих досках после swap
- Двойной snapshot (обе доски изменяются)
- Множество edge cases с другими эффектами (Frost, Blackout, Smoke)
- Самая сложная карта — реализовать последней
- Клиент: сложная анимация обмена

### Зависимости

Frost, Blackout (нужно решить взаимодействие с другими эффектами в зоне обмена). Рекомендуется реализовать последней.
