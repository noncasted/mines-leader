## Задача: Salvage — просмотр 3 верхних, взять 1

### Статус: Не начато

### Карта

| Поле | Значение |
|------|----------|
| Имя | Salvage |
| Мана | 2 |
| Цель | Self |
| Паттерн | -- |
| Категория | Колода |
| Пул | Ordinary |
| Max-вариант | Нет |

### Описание эффекта

Показывает 3 верхних карты колоды, игрок берет 1 в руку, остальные 2 возвращаются на верх колоды в произвольном порядке.

### Сложность: 5

UI для просмотра и выбора из 3 карт (новый interaction pattern). Backend: Deck.Peek(3) + выбор + возврат.

### Особые требования

- Двухфазное взаимодействие: сначала backend показывает 3 карты, потом игрок выбирает
- Возможно потребуется промежуточное сообщение (request-response) или два snapshot
- Для бота: выбирать карту с максимальной utility

### Зависимости

Нет. Но UI-паттерн "выбор из N карт" может переиспользоваться.
