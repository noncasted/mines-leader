## Задача: Focus — следующая карта -1 мана

### Статус: Не начато

### Карта

| Поле | Значение |
|------|----------|
| Имя | Focus |
| Мана | 1 |
| Цель | Self |
| Паттерн | -- |
| Категория | Усиление |
| Пул | Ordinary |
| Max-вариант | Нет |

### Описание эффекта

Следующая сыгранная карта стоит на 1 ману меньше (минимум 0). Эффект одноразовый — сбрасывается после применения к одной карте.

### Сложность: 3

Требует механизма "buff на следующую карту" — модификатор стоимости, который должен сброситься после первого использования. Нужна интеграция с CardUseCommand для проверки активных буффов.
