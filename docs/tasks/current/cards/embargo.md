## Задача: Embargo — карты противника +1 мана на 1 ход

### Статус: Не начато

### Карта

| Поле | Значение |
|------|----------|
| Имя | Embargo |
| Мана | 3 |
| Цель | Opponent |
| Паттерн | -- |
| Категория | Ресурсы |
| Пул | Ordinary |
| Max-вариант | Нет |

### Описание эффекта

Все карты в руке противника стоят на 1 ману дороже до конца его следующего хода. Не суммируется при повторном применении.

### Сложность: 4

Временный debuff на противника с длительностью 1 ход. Нужна интеграция с CardUseCommand противника для модификации стоимости + автоматическое снятие эффекта.
