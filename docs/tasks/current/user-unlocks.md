нужен реворк client/Assets/Menu/Progression backend/Meta/Users/Progression

вместо прогрессии по опыту, делаем анлок новых карт через ачивки.

1. заведи enum InGameAchievementType
2. на сервере сделай InGameAchievementOptions и IInGameAchievementConfig
3. у игрока сделай IUserInGameAchievements грейн, который будет обрабатывать статы игрока и
   выдавать ачивки.
4. создай IUserStats. статы считаются во время матча и после матча каждому игроку отправляются
   его статы и обрабатываются в грейне.
5. придумай статы которые мы считаем, например количество флагов которое игрок поставил, количество открытых клеток, выброшенные карты, количество бафов которое получил, количество клеток которые поставил на вражеском поле, сколько матчей сыграл, сколько матчей выиграл, сколько карт из каждой CardGroup выкинул и тд.
6. на основе этих статов напиши конфиг для ачивок, например: "Поставь 10 флагов", "Открой 50 клеток", "Выбрось 5 карт из CardGroup A" и т.д.
7. в консоли сделай на странице configs вкладку для редактирования ачивок.
8. ачивки у нас группируются по InGameAchievementType и имеют тиры, то есть InGameAchievementType.FlagsSet имеет 5 тиров по количеству флагов 10, 100, 1000, 10000, 100000. Каждая ачивка имеет описание и награду (например, открывает новую карту).
9. Награды сделай через IInGameAchievementReward, чтобы можно было добавлять новые типы наград в будущем.
10. У ачивки сделай IInGameAchievementCondition, в котором будет метод bool IsConditionMet(IUserStatsState stats), который будет проверять, выполнено ли условие ачивки.
11. На клиенте перепиши client/Assets/Menu/Progression, там больше не будет прогресс бара, У нас будут ряды из префабов ачивок. на префабе ачивки будет название, каунтер прогресса и иконка что там за награда. в IUserInGameAchievementReward будет одна из реализаций CardUnlockReward, которая будет иметь PossibleGroups, то есть будут ачивки которые будут выдавать именно карту конкретной группы.
