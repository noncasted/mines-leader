# Card Image Prompts

## Art Style Reference

Existing card icons are small stylized game icons with:
- Dark background (near-black, subtle vignette)
- Bright neon/magic glows as the main visual element
- Central symbolic object with particle effects, energy trails, aura
- Color palette: electric purple, neon green, fiery orange, icy blue, golden yellow
- Theme mix: military mines + magic spells + technology
- No text, no borders -- pure icon art

**Base prompt prefix (use for ALL cards):**
Game card icon, dark background, medieval pixel art, glowing magical effects, vibrant colors, centered composition, no text, no border
