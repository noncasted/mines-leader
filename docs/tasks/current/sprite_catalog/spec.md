# Sprite Catalog — spec

Authoritative contract for implementers and critics. If this file and the code disagree, this file wins. Do not invent API that is not written here.

Repo root: `/projects/mines-leader`
Unity project: `/projects/mines-leader/client`

---

## Goal

Art under `client/Assets/Art` is catalogued statically, the same way scenes are catalogued as `Scenes.GameField`.

```csharp
await builder.LoadSpriteGroup(Sprites.Cards);

_image.sprite = Sprites.Cards.Trebuchet;
Play(Sprites.Cards.BloodPact); // ISpriteAnimationData
```

If `Sprites.Cards` was not loaded through `LoadSpriteGroup`, every property getter throws. Getters never load.

---

## Locked decisions

1. `EnsureLoaded()` only throws. It never calls Addressables, `LoadGroup`, or `Retain`.
2. Loading happens only via `builder.LoadSpriteGroup(Sprites.Cards)`.
3. Each group is a generated class: `CardsSprites : SpriteGroup`.
4. `Sprites.Cards` is a stable singleton handle (`new()` at domain load), not the loaded ScriptableObject.
5. Sheet → property type `Sprite`. Animation → property type `ISpriteAnimationData`.
6. Animation time and color are authored in the Texture/Aseprite inspector module and baked into the group payload. Changing time/color does **not** regenerate C#.
7. Inspector UI is injected with `Editor.finishedDefaultHeaderGUI`. Do **not** replace `TextureImporter` / `AsepriteImporter` editors.
8. One art file = one property. One file belongs to exactly one group.
9. Source priority when the same sanitized name exists as several formats: **aseprite > psd > png**.
10. Addressable unit is one `SpriteGroupAsset` per group. Individual sprites are dependencies, not separate addressable entries.

---

## Why a separate assembly

`Internal` already references `Tools.Runtime`. `Common.Animations` already references `Internal`.

If `SpriteGroup` / generated classes live in `Tools.Runtime` and mention `ISpriteAnimationData`, `Tools.Runtime` would reference `Common.Animations` → cycle:

`Tools.Runtime → Common.Animations → Internal → Tools.Runtime`

Therefore handwritten runtime + generated group classes live in a **new** assembly:

`client/Assets/Tools/Runtime/SpriteBuilder/Tools.SpriteBuilder.asmdef`

References (use existing GUIDs from those asmdefs' `.meta`):

- `Internal` (`f039cb8c565843dba6da5b3c1ccde7d6`) — `IScopeBuilder`, `IReadOnlyLifetime`
- `Common.Animations` (`d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9`) — `ISpriteAnimationData`, `SpriteAnimationData`
- UniTask (`f51ebe6a0ceec4240a699833d6309b23`)
- Addressables (`9e24947de15b9834991c9d8411ea37cf`)

`autoReferenced`: true.

`Tools.Editor` must reference this new assembly.

Do **not** add a `Tools.Runtime → Internal` or `Tools.Runtime → Common.Animations` reference.

## API

### `SpriteGroup` (handwritten)

```csharp
namespace Tools.SpriteBuilder
{
    public abstract class SpriteGroup
    {
        public bool IsLoaded { get; }

        public async UniTask Retain() { }
        public void Release() { }

        protected abstract UniTask LoadGroup();
        protected abstract void UnloadGroup();

        protected void EnsureLoaded()
        {
            if (IsLoaded == false)
                throw new InvalidOperationException($"{GetType().Name} is not loaded");
        }
    }
}
```

- `Retain`: increment refcount; if not loaded, `await LoadGroup()` then `IsLoaded = true`.
- `Release`: decrement; at 0 call `UnloadGroup()` and `IsLoaded = false`. If count is already 0, log error and return — do not throw.
- `EnsureLoaded`: throw only. No load.
- Method name is `LoadGroup` / `Retain`, **not** `LoadGroupAsync` (no `Async` suffix on UniTask).

### Generated catalog

```csharp
// Auto-generated by SpriteGenerator. Do not edit manually.
namespace Tools.SpriteBuilder
{
    public static class Sprites
    {
        public static readonly CardsSprites Cards = new();
        public static readonly GameCellsSprites GameCells = new();
    }
}
```

### Generated group class

```csharp
public sealed class CardsSprites : SpriteGroup
{
    private const string Address = "<guid-of-Cards-SpriteGroupAsset>";

    private Sprite _trebuchet;
    private ISpriteAnimationData _bloodPact;
    private AsyncOperationHandle<SpriteGroupAsset> _handle;

    public Sprite Trebuchet
    {
        get { EnsureLoaded(); return _trebuchet; }
    }

    public ISpriteAnimationData BloodPact
    {
        get { EnsureLoaded(); return _bloodPact; }
    }

    protected override async UniTask LoadGroup()
    {
        _handle = Addressables.LoadAssetAsync<SpriteGroupAsset>(Address);
        var asset = await _handle.ToUniTask();
        _trebuchet = asset.GetSheet("Trebuchet");
        _bloodPact = asset.GetAnimation("BloodPact");
    }

    protected override void UnloadGroup()
    {
        _trebuchet = null;
        _bloodPact = null;
        if (_handle.IsValid())
            Addressables.Release(_handle);
    }
}
```

Property names: `SanitizeIdentifier` of the file name without extension (same as `ScenesClassGenerator`: keep letters and digits only). `Trebuchet_Max` → `TrebuchetMax`. `Game_Cell_Open` → `GameCellOpen`.

If the identifier is empty or starts with a digit, prefix `G`. If two files in one group collapse to the same identifier, log an error and skip the lower-priority source; do not emit two properties with the same name.

Class name: `{SanitizeIdentifier(groupName)}Sprites`. Label `Cards` → `CardsSprites`.

### Payload

One ScriptableObject type for every group:

```csharp
namespace Tools.SpriteBuilder
{
    public sealed class SpriteGroupAsset : ScriptableObject
    {
        [SerializeField] private SpriteEntry[] _entries;

        public Sprite GetSheet(string name);
        public ISpriteAnimationData GetAnimation(string name);
    }

    public enum SpriteKind { Sheet, Animation }

    [Serializable]
    public sealed class SpriteEntry
    {
        public string Name;
        public SpriteKind Kind;
        public Sprite[] Sprites; // 1 sprite for Sheet, all frames for Animation
        public float Time;
        public Color Color;
    }
}
```

- `GetSheet`: find Sheet entry, return `Sprites[0]`. Missing / empty → throw.
- `GetAnimation`: find Animation entry, return `new SpriteAnimationData(entry.Sprites, entry.Time, entry.Color)`. Missing → throw.
- Asset path: `Assets/Tools/Runtime/SpriteBuilder/Groups/{GroupName}.asset`
- Addressables: group `Sprites_{GroupName}`, Pack Together. Only this asset is marked addressable. Address = asset GUID (same pattern as `StaticScene`).

### Scope extension

```csharp
// client/Assets/Internal/Scopes/Services/Builder/SpriteBuilderExtensions.cs
namespace Internal
{
    public static class SpriteBuilderExtensions
    {
        public static async UniTask LoadSpriteGroup(this IScopeBuilder builder, SpriteGroup group)
        {
            await group.Retain();
            builder.Lifetime.Listen(() => group.Release());
        }
    }
}
```

Internal already references Tools.Runtime; it must also reference `Tools.SpriteBuilder`.

Refcount matters: Menu and GamePlay may both `LoadSpriteGroup(Sprites.Cards)`. Unloading Menu must not unload Cards from under GamePlay.

## Inspector module

Hook: `[InitializeOnLoad]` static ctor → `Editor.finishedDefaultHeaderGUI += Draw`.

Show only when:

- every target is `AssetImporter` (`TextureImporter` or Aseprite `ScriptedImporter`)
- asset path starts with `Assets/Art/`

Layout (IMGUI box, under the Addressable checkbox):

```
┌ Sprite Catalog ──────────────────────┐
│ Kind:   ○ Sheet   ● Animation        │
│ Group:  [ Cards              ▾ ] [+] │
│ Time:   [ 0.80                 ]     │  // Animation only
│ Color:  [ ■                    ]     │  // Animation only
└──────────────────────────────────────┘
```

- `[+]` switches the row to a text field + OK/Cancel. OK appends the name to the group registry and selects it.
- Multi-object: mixed values show as mixed; writing applies to every target.
- Persist immediately (like the Addressable checkbox). Do **not** call `SaveAndReimport()`. Write `.meta` via `importer.userData` + `EditorUtility.SetDirty` + `AssetDatabase.WriteImportSettingsIfDirty`.
- Time/Color visible only when Kind is Animation. Switching Sheet → Animation fills defaults: `time = 0.8`, `color = white`.
- After a metadata change, debounce (`~0.5s`) and run `SpriteGenerator.Generate()`. Changing only time/color updates the payload asset and must **not** rewrite `*.cs` if the property set is unchanged.

### Storage (`importer.userData`)

Namespaced JSON. Merge, do not wipe unrelated `userData`.

```json
{
  "spriteCatalog": {
    "group": "Cards",
    "kind": "Animation",
    "time": 0.8,
    "color": { "r": 1, "g": 1, "b": 1, "a": 1 }
  }
}
```

`kind`: `"Sheet"` | `"Animation"`.

If `spriteCatalog` is missing: treat as unassigned. Defaults when first shown:

- group from folder under `Assets/Art`: join directory names, sanitize. `Art/Cards/X` → `Cards`. `Art/Game/Cells/X` → `GameCells`. `Art/Menu/Main/X` → `MenuMain`.
- kind: Aseprite with more than one frame → `Animation`, otherwise `Sheet`.

### Group registry

`client/Assets/Tools/Editor/SpriteBuilder/SpriteGroups.json`

```json
{ "groups": [ "Cards", "GameCells", "MenuMain" ] }
```

Dropdown = union of this list and groups discovered while scanning `Assets/Art`. Creating a group writes the file. The file is the list of known names, not the list of sprites.

## Generator

Mirror `SceneGenerator` / `ScenesClassGenerator`.

Editor entry points:

- `[InitializeOnLoadMethod]`
- `[MenuItem("Tools/GenerateSprites")]`

Scan: `Assets/Art`, extensions `.aseprite`, `.psd`, `.png`. Skip files without `spriteCatalog.group` after applying folder default (always assign a default group on first generate if missing, then persist userData).

For each group:

1. Dedup by sanitized property name using source priority.
2. Create/update `Assets/Tools/Runtime/SpriteBuilder/Groups/{Group}.asset` with sprite references and time/color.
3. Mark that asset addressable in group `Sprites_{Group}`.
4. Emit `Generated/{Group}Sprites.cs` and `Generated/Sprites.cs`.

C# write rule (same as scenes): if file content is identical, do not write (avoid domain reload).

C# **must** be rewritten only when the set of `(group, propertyName, kind)` changes. Time/color changes update the `.asset` only.

Generated files:

```
client/Assets/Tools/Runtime/SpriteBuilder/
  Tools.SpriteBuilder.asmdef
  SpriteGroup.cs
  SpriteGroupAsset.cs
  SpriteKind.cs          // or nest SpriteKind in SpriteGroupAsset.cs
  Groups/
    Cards.asset
  Generated/
    Sprites.cs
    CardsSprites.cs
    GameCellsSprites.cs
```

Editor files:

```
client/Assets/Tools/Editor/SpriteBuilder/
  SpriteCatalogInspector.cs
  SpriteCatalogMetadata.cs
  SpriteGroupsRegistry.cs
  SpriteGenerator.cs
  SpritesClassGenerator.cs
  SpriteAddressablesSync.cs
  SpriteGroups.json
```

Sheet sprite pick order: sub-asset named like the file, else the first `Sprite` from `LoadAllAssetsAtPath`. Animation frames: all `Sprite` sub-assets in importer/frame order (Aseprite `animatedSpriteImportData` order).

## Style (project rules)

Follow `.agents/docs/CODE_STYLE_FULL.md` and `.agents/docs/API_DESIGN_FULL.md`:

- braces on the same line
- member order: ctor → readonly fields → mutable fields → public methods → private methods → local functions
- fields `_camelCase`, no abbreviations
- no `Async` suffix on `UniTask` methods
- collections: `IReadOnlyList<T>`, never return null
- `try/catch` around file IO, `Debug.LogError`, do not crash the editor generate path
- generated header: `// Auto-generated by SpriteGenerator. Do not edit manually.`

## Explicitly forbidden

- `[CustomEditor(typeof(TextureImporter))]` or wrapping the internal `TextureImporterInspector`
- `EnsureLoaded` / property getters calling Addressables or `Retain`
- `SaveAndReimport` when only catalog metadata changed
- Marking every sprite/png/aseprite addressable individually
- Putting catalog art in `Resources`
- One central SO as the source of truth for group membership (source of truth is per-asset `userData`)
- `Tools.Runtime` referencing `Internal` or `Common.Animations`
- Lazy-loading a group on first property access
- Regenerating C# because time/color changed

- `builder.Lifetime.Listen(() => group.Release())`
- Unload clears fields and `Addressables.Release`s the handle

Acceptance:

- [ ] game code loads only through `builder.LoadSpriteGroup`
- [ ] two `Retain` + one `Release` leaves the group loaded
- [ ] `Release` to 0 calls `UnloadGroup` and `IsLoaded == false`
- [ ] getters still throw when not loaded
- [ ] no `Async` suffix
- [ ] lifetime callback is the only automatic unload
